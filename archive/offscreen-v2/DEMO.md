# DEMO.md: the 3:00 run (v2, organic)

We don't know which errand we will run. Neither do the judges. That is the demo.

## Roles
- Hands: a teammate, blindfolded, seated at the bottom edge of the frame.
- Presenter: Saran, beside the screen. Reads the errand aloud. Says only what the screen shows.
- Operator (optional): at the laptop, hands off unless a fallback is needed.

## Run of show
| Time | What happens (live) | Presenter |
| --- | --- | --- |
| 0:00 | QUEUE on screen: errands from the room today, each with sender and time. | Opening (below). |
| 0:15 | The oldest doable errand starts. (A judge's errand, if offered, starts compiling in the background.) Open scan of the table as it is. | Reads the errand and the sender's name aloud. |
| 0:20 | AGENT researches the errand's rules live (URLs on screen), writes checks, tests them on this scan. The hook releases the plan. | "It can't release a plan until its own tests pass." |

| 2:20 | If a judge gave an errand: its plan is ready. Run its first steps or offer to run it after. | "Yours is ready." |
| 2:35 | The WALL: every run today, failures included. Raw vs Offscreen counts. | "Same model, same table, same errands. Raw: [n] of [n]. Ours: [n] of [n]." |

## Opening (say it aloud 10 times; under 25 s)
"Every agent this fall stops at the screen. Ours doesn't. And we don't pick its jobs. These errands came from people in this room today. We haven't seen this table through its eyes, and we don't know which one runs next. Here it is."

## Close (under 10 s)
"We didn't choose that errand. We didn't set that table. It still got it right, and it can prove every step."

## Rules for the run
- Never pick the errand. Run the oldest doable one, or the judge's.
- Never tidy or arrange the table before a run.
- No staged mistakes. Zero stops is a fine outcome.
- If the agent says "can't do", read its reason aloud and run the next one. That moment builds trust.
- If the compile passes 60 s, the fast path runs labeled "unverified" until the checks arrive.

## Inviting judges (never required)
- "Give it an errand you'd do with your hands. Or just move anything on the table."
- If they say no, nothing changes. The queue already has errands that are not ours.

## Reset between runs (60 s)
Put objects back roughly where they were, not on marks. Empty the zones. New run id.

## Q&A (one breath each)
- Did you plant the errand? The sender and the time are on screen. Give it yours.
- Did you set the table? It's our real table. Move anything and watch it replan.
- How is this different from Tasks in Gemini? Tasks finishes errands in apps. Offscreen finishes the physical part and proves each step, on the same Hydrogen model.
- Astra's bike demo did this. That 2025 video found the manual and called a shop while the person did the work and checked it himself. Offscreen plans, watches every step, and stops mistakes before they land, on errands it has never seen.
- Why the blindfold? So every success belongs to the model.
- What does the Managed Agent do that a script can't? It triages errands nobody wrote for it, researches their rules, writes the checks as code, tests them on this camera, and cannot release until its tests pass. Every 30 minutes it learns from new runs, and a second hook stops it from breaking old cases.
- What can't it do? Folding, tying, assembling, cooking. It says so.
- Can a robot use it? The plan and checks talk about objects, zones and verification, not hands. Every run is logged with frames, tracks and checks.
